# MiuBarrd

# 项目简介

MiuBarrd​ 是一款基于 SFML​​ 构建的轻量级电子白板。
它专注于提供极速的渲染性能与极简的开发体验，同时通过灵活的插件系统赋予其强大的可扩展性。

轻量：核心精简，无冗余依赖，启动迅速。

快捷：智能化操作，多指操作等应有尽有。

免费：开箱即用，MiuBarrd不要求任何的费用或者激活代码等花里胡哨的东西

# 技术架构

渲染引擎​：基于 SFML 的高性能 2D 图形引擎，提供硬件加速渲染

底层框架​	：SFML (Simple and Fast Multimedia Library)	跨平台多媒体库，处理窗口、图形、输入、音频

插件系统​	：动态加载模块，支持运行时加载/卸载插件，扩展功能无需重新编译

# 核心特性

基于批处理渲染管线

自动批合并（Batch Merging），减少 draw call

支持 VBO / VAO 硬件加速

# 开发方向

-完整的插件生态

-优化体积变得更加的轻量

-接入AI的高级功能

-跨平台支持（目前仅支持Windows10+）

-自动更新等网络操作
